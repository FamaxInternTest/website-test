# Demo Precision Sdn Bhd — Company Website

A one-page static website for **Demo Precision Sdn Bhd**, a fictional precision
manufacturing company based in Kedah, Malaysia. The site introduces the
company's services, announces an Open Day and provides contact details.

> **Note:** This is a fictional company and website, created for a training
> exercise. All content is invented; no real company, customer, email or data
> is used.

## What it is

- A single-page website built with plain HTML, CSS and JavaScript.
- Generated with Google AI Studio.
- No frameworks, no build step, no external fonts and no external scripts.
- Fully self-contained: the page makes **zero third-party requests**.
- Responsive layout with **no horizontal scrolling at 360 px**.
- Total page weight **under 1 MB**.
- Includes `<meta name="robots" content="noindex">` — the page is not meant
  for search engines.
