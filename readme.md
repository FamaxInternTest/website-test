# Demo Precision Sdn Bhd — Static Website

A self-contained, one-page static website for Demo Precision Sdn Bhd, a precision manufacturing company based in Kedah, Malaysia, serving customers who make electronics and automotive parts.

## Project Structure

All files reside in a single directory with zero build steps or external dependencies:

```text
├── index.html    # Semantic HTML5 document structure
├── styles.css    # Responsive styles, layout, and colour scheme
├── script.js     # Vanilla JavaScript for menu and form behaviour
└── README.md     # Project documentation
